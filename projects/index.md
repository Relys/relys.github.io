<h2>3DS Multi Decryptor <span class="entry-date">Aug 2014 – Mar 2015</span></h2>
<p>A suite of tools built around the ARM9 security processor's AES engine, reverse-engineering keyY/IV generation to decrypt NCCH partitions, SD card content, NAND FAT16 images, and the title key database. Over 250,000 unique views on release and the base for numerous forked open-source utilities.</p>
<ul>
  <li><a href="https://github.com/Relys/3DS_Multi_Decryptor" target="_blank">Source on GitHub</a></li>
</ul>
